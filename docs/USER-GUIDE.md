# 使用说明

**图片批注查看器**是一款轻量的图片查看 + 可编辑批注工具：截图工具会损失分辨率、画完就改不了，PS 又太笨重——它正好填补中间的空档。批注以对象形式存在，画错了随时可以重新选中、移动、改颜色或删除；导出时按**原图分辨率**合并，不损失画质。

---

## 1. 快速上手

### 打开图片（四种方式）

1. **文件对话框**：点击顶部工具栏的「打开」按钮，或点击首页引导区的虚线框；
2. **拖拽**：把图片文件直接拖进应用窗口任意位置；
3. **Ctrl+V 粘贴**：截图（如微信/QQ/系统截图）后，在应用中直接按 `Ctrl+V` 粘贴剪贴板里的图片；
4. **应用内截图**：点击顶部「截图」按钮或按 `Ctrl+Shift+S` 抓取整个屏幕/某个窗口；桌面版还可用「自由截图」剪刀按钮或全局热键 `Ctrl+Shift+P` 拖框截取任意区域，截完直接载入（详见下节）。

### 截图（看图 → 截图 → 标注闭环）

应用内置两种截图方式，不用再开其他截图软件：

**方式一：「截图」按钮——系统选源（桌面版 / 网页版一致）**

点击顶部工具栏的「截图」按钮（显示器图标，或按 `Ctrl+Shift+S`）：

1. 弹出「选择要分享的内容」对话框（桌面版为系统选源窗口，网页版由浏览器弹出，都是系统安全机制，属于正常现象，不是应用本身的弹窗）；
2. 在对话框里选择 **整个屏幕 / 某个窗口**（网页版还可选标签页），点击「分享」；
3. 截取的画面（按该画面的原始分辨率）自动载入工作区成为当前图片，文件名形如 `截图_20250113-153042.png`，可以立刻接着标注；只要局部的话，再用「裁剪」工具（`C`）框取即可；
4. 若在选择器里点了「取消」，状态栏提示"已取消截图"，当前工作区不受影响。

**方式二：「自由截图」——冻结拖框选区（仅桌面版）**

点击顶部工具栏的剪刀图标按钮，或在任意时刻按下全局热键 `Ctrl+Shift+P`（无需先聚焦应用窗口）：

1. 所有显示器的画面瞬间冻结，每块屏幕各盖一层选框遮罩；
2. 在**任意一块屏幕**上按住拖出选框（开始拖框后其他屏幕自动恢复），松手即完成截取；
3. 截取的选区按原始分辨率自动载入工作区，可以立刻接着标注；
4. 按 `Esc` 随时取消，当前工作区不受影响。

说明：

- 两种方式都只抓取一帧静态画面：方式一抓完立即停止采集（系统录屏指示随之消失），不会持续录屏；方式二松手或取消后屏幕立即恢复；
- 截图载入与「打开新图片」行为一致：会清空当前画布与撤销历史，标注中的图片请先导出；
- 方式一需要 Chrome / Edge / Firefox 桌面版（桌面版应用内置支持），且页面运行在 localhost 或 HTTPS 环境；不支持的浏览器点击按钮会在状态栏提示；
- 系统安全界面（如锁屏、UAC 弹窗）无法被截取。

### 支持的格式

| 格式 | 解码方式 | 说明 |
| --- | --- | --- |
| JPG / PNG / GIF / WebP / BMP / AVIF | 浏览器原生解码 | GIF 取第一帧 |
| **TGA** | 内置自研解码器 | 支持 type 2/10 真彩（24/32 bpp）、type 3/11 灰度，含 RLE 压缩与 origin 翻转 |
| **TIFF** | utif 库 | 取第一帧，常见压缩格式均可 |

打开后底部状态栏会显示文件名、像素尺寸、格式和当前缩放比例。

## 3. 批注工具

左侧工具条共 11 个工具。**所有批注都是独立对象**：用「选择」工具点击任意批注即可再次选中，然后拖动移动、拉伸边角缩放、旋转，或按 `Delete` 删除——绝不会像截图工具那样画死。

| 工具 | 快捷键 | 用法 |
| --- | --- | --- |
| 选择 | `V` | 单击选中批注；拖动移动；边角手柄缩放；顶部手柄旋转；空白处拖出选框可多选 |
| 画笔 | `P` | 按住鼠标自由绘制曲线 |
| 直线 | `L` | 按住拖拽，从起点画到终点 |
| 箭头 | `A` | 按住拖拽，终点处自动生成箭头 |
| 矩形 | `R` | 按住拖拽画出矩形框 |
| 椭圆 | `O` | 按住拖拽画出椭圆 |
| 文字 | `T` | 单击放置文字框并立即输入；**双击**已有文字可再次编辑 |
| 马赛克 | `M` | 拖出矩形区域，松开后该区域底图被像素化（只影响底图，不影响其他批注） |
| 裁剪 | `C` | 拖出要保留的矩形区域（框外变暗），`Enter` 或浮动条「确认裁剪」完成裁剪，`Esc` 取消；详见下文「裁剪」 |
| 橡皮擦 | `E` | 按住拖过批注，高亮的对象在松手后删除（可 `Ctrl+Z` 撤销） |
| 抓手 | `H` | 拖拽平移视图，不产生批注 |

### 属性面板（左侧工具条下方）

- **颜色**：9 色常用色板 + 自定义取色（「+」按钮打开系统取色器）。文字颜色同样取此色。
- **线宽**：1 ~ 40 px 滑块，作用于画笔/直线/箭头/矩形/椭圆的描边。
- **线宽基准**（线宽下方「屏幕 / 图像」切换，同时作用于字号）：
  - **屏幕恒定**（默认）：任何缩放下画出来的线看起来一样粗（内部按"设置值 ÷ 当前缩放"换算），所见即所得；
  - **图像恒定**：线宽/字号固定为 N 个图像像素，缩放越大看起来越粗，但导出后该线在原图上的像素宽度恒定——适合需要精确标注尺寸的场景。
- **填充**：勾选后，矩形 / 椭圆用当前颜色实心填充。
- **字号**：10 ~ 120 滑块，作用于新放置的文字（同样受线宽基准开关控制）。

> 属性对**之后创建**的批注生效；想改已有批注，用「选择」工具选中后在色板上点新颜色（描边类批注）即可改色。

### 撤销 / 重做 / 清空

- 撤销：`Ctrl+Z`；重做：`Ctrl+Shift+Z` 或 `Ctrl+Y`（最多 50 步）。
- 清空全部批注：顶部垃圾桶按钮，有确认提示；误清也可 `Ctrl+Z` 找回。

### 裁剪（去掉框外内容）

按 `C` 或点击左侧「裁剪」图标进入裁剪模式（截图后取局部、裁普通图片都适用）：

1. 在图上**拖出要保留的矩形区域**——框外变暗、框边界高亮并带四角标记；拖错了直接重新拖框覆盖上一个；
2. 按 `Enter` 或画布上方浮动条的「**确认裁剪**」完成裁剪；按 `Esc` 或「取消」放弃；
3. 确认后：底图裁到选区，批注整体跟随平移，**完全落在框外的批注会被删除**（部分重叠的保留），视图自动适应窗口；
4. 选区小于 8×8 图像像素时确认无效，状态栏会提示，重新拖框即可；
5. 裁剪是**可撤销的**：一步 `Ctrl+Z` 连底图带批注一起回到裁剪前，`Ctrl+Y` 重做；
6. 裁剪模式下其他绘制手势不生效；切换到其他工具会自动取消未确认的选框。

## 4. 导出另存

点击顶部「导出」按钮，打开导出面板：

- **格式**：PNG（无损）或 JPEG（带 10%~100% 质量滑块，默认 92%）。
- **文件名**：默认为 `原名_批注.png`（或 `.jpg`），可修改。
- **分辨率**：始终按**原图分辨率**导出。例如原图 6000×4000、屏幕上缩到 25% 查看，导出的仍是 6000×4000，批注等比例放大合并，清晰度和原图一致。
- **保存方式**：Chrome / Edge 会弹出系统「另存为」对话框，可自由选择保存位置；其他浏览器自动下载到默认下载目录。
- **JPEG 说明**：透明区域会自动铺白底。

**没有批注也可以导出**——这相当于一个本地格式转换器：把 TGA / TIFF 打开后直接导出为 PNG / JPEG，非常实用。

## 6. 常见问题 FAQ

**Q1：批注会写进原图文件吗？**
不会。批注只存在于应用的内存画布中，原始图片文件永远不会被修改。只有当你点击「导出」时，才会生成一张**新的**合并了批注的图片文件。

**Q2：导出的图片为什么和原图一样清晰？**
因为导出不是"截屏"。应用内部始终以原图像素坐标保存批注，导出时把画布临时切换回原图分辨率重新渲染，再保存为 PNG/JPEG，所以不会有屏幕分辨率的损失。

**Q3：画错了能改吗？**
能。批注是对象而不是像素：用选择工具（`V`）点选后可以移动、缩放、旋转、删除；也可以 `Ctrl+Z` 逐步撤销（最多 50 步）。

**Q4：马赛克之后还能还原吗？**
马赛克对象本身可以选中、移动或删除（删除后底图原样露出，因为底图从未被修改）。但**已导出**的马赛克区域是真正像素化的，无法从导出文件里还原——这正是马赛克的意义。

**Q5：TGA / TIFF 打开失败？**
TGA 支持 type 2/10 真彩（24/32 bpp）与 type 3/11 灰度，**不支持彩色映射（type 1/9）和 15/16 bpp**；TIFF 依赖 utif 解码，只取第一帧，个别罕见压缩（如 JPEG-in-TIFF）可能不支持。失败时底部状态栏会显示具体原因。

**Q6：为什么 Firefox 里导出没有「另存为」对话框？**
「另存为」对话框用的是 File System Access API，目前只有 Chrome / Edge 支持。Firefox / Safari 会自动降级为普通下载，文件在浏览器默认下载目录。

**Q7：打开新图片后，之前那张的批注还在吗？**
不在了。打开新图片会清空当前画布与撤销历史。请先导出再打开下一张。

**Q8：文字怎么改内容 / 字号？**
双击文字进入编辑状态即可改内容。字号在放置前由左侧「字号」滑块决定；已放置的文字可以用选择工具拉伸边角整体缩放。

**Q9：支持哪些来源的粘贴？**
任何写入剪贴板的位图：系统截图（Win+Shift+S）、微信/QQ 截图、浏览器里"复制图片"等，按 `Ctrl+V` 即可打开。

**Q10：应用会把我的图片上传到服务器吗？**
不会。所有解码、批注、导出都在浏览器本地完成，没有任何网络上传行为，可断网使用。
